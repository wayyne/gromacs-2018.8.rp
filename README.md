# gromacs-2018.8.rp

This is a modified version of GROMACS 2018.8 for the purpose of generating training data and deploying machine-augmented molecular dynamics (MAMD) simulations.

The files for the modified force-field discussed in the MADM diatomics manuscript can be found in the rp_diatomics directory.

Tensorflow C API is required.

Otherwise the canonical gromacs installation process still applies.

Files for patching the opalsAA force field for the diatomics described in the manuscript are also in rp_diatomics, and in build.
